# 实例练习说明（第二批）

学习材料：
1. Packaging and Shipping Code — https://missing-semester-cn.github.io/2026/shipping-code/
2. Agentic Coding — https://missing-semester-cn.github.io/2026/agentic-coding/
3. PyTorch 中文教程索引 — https://docs.pytorch.ac.cn/tutorials/index.html

环境：macOS（Apple Silicon）、Homebrew Python 3.14.7、venv 虚拟环境（.venv）、torch 2.14.0。
所有实例均在「终端」中逐条输入命令完成（未用 `&&` 串联、基本未用管道），每条操作后即时截图；截图只保留命令与输出，已裁掉窗口框架，存于 `shots/`，原始窗口图存于 `shots/_archive/`。

## 一、Packaging and Shipping Code（5 个实例）

| 实例 | 截图 | 命令/操作 | 对应课堂知识点 |
|---|---|---|---|
| 1 | 01_venv.png | `python3.14 -m venv .venv` → `source .venv/bin/activate` → `which python`、`python --version` | 依赖与环境：用虚拟环境隔离项目依赖 |
| 2 | 02_pip.png | `pip install requests` → `pip list` → 导入验证 | 依赖解析：自动安装传递依赖（certifi、idna、urllib3、charset-normalizer） |
| 3 | 03a_build.png / 03b_wheel.png | 编写 `pyproject.toml` 与 `greeting.py`，`python -m build -q` 构建 sdist+wheel；`unzip -l` 查看 wheel 内容；`pip install` 本地 wheel 后运行入口命令 `greet World` | 产物与打包：wheel 是 zip 格式、[project.scripts] 声明命令行入口 |
| 4 | 04_freeze.png | `pip freeze > requirements.txt`，`wc -l`、`cat` 查看 | 版本锁定：用 lock 文件精确固定全部依赖版本以复现环境 |

相关文件：`greeting_pkg/`（打包源码与 dist 产物）、`requirements.txt`。
